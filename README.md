# Sushil Shakya — Multi-Page Portfolio

Personal portfolio website built for GitHub Pages (`sushilsayshello.github.io`).

## Structure
- `index.html` — Executive Summary & Core Competencies
- `about.html` — Background & Education
- `experience.html` — Professional Experience & Technical Skills Matrix
- `projects.html` — SOC Labs, Research & Hackathon Prototypes
- `achievements.html` — Honors, Awards & Certifications
- `contact.html` — Contact Information & Direct Inquiry Form
- `404.html` — Custom GitHub Pages 404 Error Page
- `css/style.css` — Shared Cyber-Slate Stylesheet

## Deployment on GitHub Pages
1. Extract this archive and upload all files/folders to the root of your `sushilsayshello.github.io` repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (`main` / `/ (root)`) and click **Save**.
